# FlowEditor

Responsibilities:
- Hybrid migration path for existing web-based flow editor.
- Resolve editor launch URI (embedded bundle or remote URL).
- Prepare runtime bootstrap payload for WebView host integration.

Implemented:
- `FlowEditorMode`
- `FlowEditorBridgeOptions`
- `FlowEditorBridgeService`
- `LocalBundleWebHost`
- `FlowEditorHostRuntime`
